winget-accel — 让 winget 在国内网络下能下得动
================================================

这个程序在本机跑一个小代理，只把 4 个 GitHub 下载域名指给它，
再由它把请求转给 GitHub 加速服务。winget 的命令、源、清单都不变，
只有"下载安装包"这一段被加速。


不支持 git clone
----------------
本工具只针对 winget 安装包下载，不是 GitHub 通用代理。
git clone / git-upload-pack 等路径会被 PAC 默认设为 DIRECT，
本工具不保证也不承诺 git clone 的兼容性或速度。

下载速度实测：从 21 KB/s（直连，winget 会 37 秒超时失败）
提升到 300–700 KB/s（经本代理）。


三步开始
--------

1) 双击 winget-accel.exe

   第一次运行会弹出 Windows 的安全警告，问你是否信任一张本地根证书
   —— 点「是」。这是本程序唯一需要你确认的地方。

   然后会看到两行提示，说明代理已在 127.0.0.1:8443 上运行。
   这个窗口不要关，关掉就等于停了代理。

2) 另开一个窗口，正常使用 winget

   winget install Git.Git
   winget download --id junegunn.fzf --download-directory C:\Users\你\Downloads\test

   不需要任何额外参数。

3) 停止：回到第 1 步那个窗口，按 Ctrl+C

   代理会退出，并把系统代理设置还原。


如果你想先看看它要改什么
------------------------

    winget-accel.exe --doctor

只做体检、不改任何系统设置。会报告端口、证书、PAC、5 个加速器的可达性。
建议第一次使用前先跑一次。


为什么需要那张根证书
--------------------

代理只能看到 "CONNECT github.com:443"，之后是加密的字节流。
要把它转给加速服务并让 winget 接受返回的数据，本程序必须自己扮演 github.com
—— 这在技术上就是中间人，必须有一张你系统信任的证书。

为了把风险收敛，这张证书被限制成"只能签发下面 4 个域名"：

    github.com
    objects.githubusercontent.com
    codeload.github.com
    release-assets.githubusercontent.com

签其它任何域名都会被 Windows 拒绝（这一条我实测验证过）。
所以最坏情况是"有人能冒充这 4 个下载站"，无法冒充银行、邮箱、公司内网。

另外，安装包下载完后 winget 仍会用官方清单里的哈希校验一遍
—— 也就是说内容有没有被改过，winget 自己会拦。


安全提醒
--------

- certs\ 目录里是本机 CA 的私钥，不要把它打包发给别人，也不要放进网盘同步目录。
- 这个证书 1 年后到期。到期前 7 天程序会自动更换，届时需要你再点一次「是」。


出问题怎么办
------------

Q: 双击后报 "CA 导入被系统拒绝 0x80070032 / 0x80070005"
A: 多半是安全软件（火绒、360、电脑管家等）拦了写入证书存储。二选一：
   1. 退出安全软件后重新双击
   2. 手动导入：Win+R 输入 certmgr.msc → 「受信任的根证书颁发机构」
      → 右键「所有任务」→「导入」→ 选 certs\ca-cert.pem

Q: winget 下载时提示证书错误（0x80072f89 / TRUST_E_CERT_SIGNATURE）
A: 根存储里有一张同名的旧证书，而当前用的是新证书。执行：
      winget-accel.exe --remove-ca
   然后重新双击 winget-accel.exe，点「是」。

Q: 用了没效果，winget 还是慢
A: 先跑 winget-accel.exe --doctor 看 chain 那一行是不是 "5/5 个候选可达"。
   如果候选都不可达，说明加速服务此刻不通；如果可达但仍慢，
   看 proxy.log 里有没有 REWRITE 开头的行 —— 没有就说明 winget 没走代理
   （可能是 winget 版本改了下载器行为）。

Q: 想彻底卸载
A: 1. Ctrl+C 停掉代理（会自动还原 PAC）
   2. winget-accel.exe --remove-ca          （删掉根证书）
   3. 删掉整个文件夹


系统要求
--------

Windows 10 / 11，64 位（x64）。
不需要管理员权限，不需要安装 VC++ 运行库，不需要 .NET。

已验证的环境：Windows 10.0.26100、winget v1.29.380。
其它版本未验证 —— 如果跑不起来，请把 --doctor 的输出发出来。
